# 镇静催眠药演进图谱

GABA 能镇静催眠药物的交互式教学页面，面向药学、医学学习者，界面为中文。

**在线访问：** https://lz1933620071-skyrim.github.io/a/

## 内容

页面梳理四代药物的演进，主线是安全性与选择性的提高：

| 类别 | 收录药物 |
|---|---|
| 酒精 | 乙醇 |
| 巴比妥类 | 苯巴比妥、戊巴比妥、司可巴比妥、硫喷妥钠 |
| 苯二氮䓬类（BZD） | 阿普唑仑、地西泮、劳拉西泮、氯硝西泮、三唑仑 |
| Z 类药物 | 唑吡坦、佐匹克隆、右佐匹克隆 |

顶部药物选择器在所有模块间联动。

- **总览**：可点击的历史时间轴，以及按结合位点、GABA 依赖性、天花板效应、治疗窗、依赖风险、CYP 诱导、特异性拮抗剂等维度的对比矩阵。
- **模块 1 · 分子结构**：2D 结构（SmilesDrawer）与 3D 计算构象（3Dmol.js），可点击的结构要点高亮与结构对比，BZD 构效关系实验台。
- **模块 2 · 作用机制**：GABA<sub>A</sub> 受体俯视图与剖面图、单通道开放示意（频率与时长）、α 亚型选择性、非 GABA 靶点、示意性剂量-效应曲线。
- **模块 3 · 药代动力学**：可叠加的血药浓度-时间曲线（含肝功能受损、老年人、CYP3A4 抑制剂、CYP 诱导等情境），对比表，乙醇零级动力学与 ALDH2，硫喷妥两室模型。
- **模块 4 · 临床与安全**：适应证、戒断严重程度、老年人用药、复杂睡眠行为、交叉耐受与近似等效剂量、联用风险组合选择器。

可直接链接到某个模块：`#home`、`#structure`、`#mechanism`、`#pk`、`#clinical`，例如 https://lz1933620071-skyrim.github.io/a/#pk 。

## 数据来源

- SMILES 取自 PubChem 记录（经镜像获取），并用 RDKit 计算 InChIKey 与 PubChem 记录逐一核对；3D 构象为 RDKit 计算构象。
- 药代与临床数据来自 FDA 说明书、监管机构通讯、指南与文献，每个模块底部列出参考来源，并标注可信度：✅ 原文摘录、🔶 二手 / 综述、❓ 待核实。
- 曲线与模拟为示意，纵轴归一化；凡有说明书或研究数据的倍数已注明来源。

## 文件

- `gaba-sedatives.html`：完整页面，单个 HTML 文件，SmilesDrawer 与 3Dmol.js 通过 jsDelivr CDN 加载。
- `index.html`：跳转到上述页面，供 GitHub Pages 根地址使用。

本地查看时直接用浏览器打开 `gaba-sedatives.html` 即可（需联网加载 CDN 库与字体）。

## 声明

本页仅用于药理学教学，比较机制与特点。页面中的等效剂量换算只作教学参考，各来源差异较大；不提供用药方案（给药频次、疗程、减量方案等），不能替代专业医疗建议。
